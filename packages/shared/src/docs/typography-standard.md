
# MKS ARTIKEL STYLE GUIDE & TYPOGRAPHY STANDARD

Dokumen ini adalah referensi baku untuk *Text Generation* (AI) maupun penulisan manual artikel di platform Mesin Kasir Solo. Output akhir yang diharapkan adalah **Raw HTML String**.

---

## MODUL STANDARISASI

Pilih modul untuk melihat detail spesifikasi:

1.  [**VOICE & TONE**](./typography/voice-tone.md) - Gaya bahasa, persona, dan diksi "Street Smart".
2.  [**HTML STRUCTURE**](./typography/html-structure.md) - Tag HTML wajib dan hirarki tipografi.
3.  [**TEMPLATES**](./typography/templates.md) - Contoh snippet artikel yang valid.
4.  [**AI PROMPTS**](./typography/ai-prompts.md) - Instruksi sistem untuk LLM (Gemini/ChatGPT).

---

*Note: Pastikan setiap artikel yang di-generate mematuhi standar ini agar visual di CMS dan Website tetap konsisten.*
